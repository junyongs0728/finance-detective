    ABOUT FINANCE DETECTIVE

    답변의 근거까지 확인합니다.

    기업의 수치와 긴 공시를 함께 읽기 위해 만든 재무 분석 웹 앱입니다.

    숫자를 조회한 다음의 질문

    재무 수치를 찾는 일과 공시에서 설명을 찾는 일을 연결했습니다. 사용자는 기업을 선택하고 질문하며, 답변에 사용한 계산·원문·도구 실행 과정을 함께 확인할 수 있습니다.

    전체 앱은 React와 FastAPI로 구현했습니다. 이 공개 화면에서는 계산, 공시 설명, 답변 보류의 저장된 실행 사례를 살펴볼 수 있습니다. 전체 앱의 실행 방법과 코드는 GitHub에 공개했습니다.

    코드와 실행 방법 ↗프로젝트 소개 PDF ↗

    질문에서 답변까지

    1. 기업과 공시 선택

      SEC·OpenDART에서 연간 수치를 수집하고 기간·통화·공시 출처를 보존합니다.

    2. 조회 또는 도구 선택

      단순 수치 조회는 정해진 경로로 처리합니다. 복합 질문은 LangGraph Agent가 조회·계산·검색·근거 추적 도구를 선택합니다.

    3. 검색과 계산

      pgvector·BM25 검색 순위를 결합해 문단을 찾습니다. 계산은 Python이 검증한 재무 수치로 수행합니다.

    4. 근거 검토와 결과 기록

      출처와 인용문을 대조하고 별도 LLM으로 주장 근거를 검토합니다. 실행·비용·프롬프트 버전을 PostgreSQL에 기록합니다.

    구현하며 확인한 것

    검색 결과가 있어도 답변은 틀릴 수 있습니다.

    사업부 요약에 회사 전체 수치를 섞는 오류를 근거 검토에서 발견했습니다. 질문 범위에 맞도록 프롬프트를 고치고 응답 스키마에도 제약을 적용했습니다.

    비용은 호출 전에 확인합니다.

    작업별 예산을 먼저 예약하고 사용자별 한도를 적용합니다. 같은 조건의 검증된 답변은 캐시로 재사용합니다.

    그래프의 필요성도 검토합니다.

    기업·공시·기간·관측값·지표·근거의 관계를 정의하고 Neo4j로 탐색하는 PoC를 구현했습니다. 현재 짧은 근거 경로는 SQL JOIN으로도 구현할 수 있습니다.
