System design

도구 선택은 AI가, 계산과 제약은 코드가.

  1. React → FastAPI기업 선택과 질문 수신. 사용자·기업·기간·요청 범위를 확인합니다.
  2. 수치 조회 또는 RAG / Agent단순 조회는 정해진 경로로, 복합 질문은 LangGraph의 모델·도구 루프로 처리합니다.
  3. Python 도구와 하이브리드 검색관측값 ID 기반 계산, pgvector + BM25 검색 순위를 RRF로 결합합니다.
  4. 답변과 근거 검증출처 구간 ID·원문 인용을 대조하고 별도 LLM이 주장과 근거를 검토합니다.
  5. 결과·비용·실행 기록공시·모델·프롬프트 버전과 실행 기록을 남겨 실패를 재현합니다.

Engineering decisions

무엇을 만들었는지보다, 무엇을 확인했는지.

검색 성공 ≠ 답변의 근거 충족

삼성전자 사업부 요약에 회사 전체 투자·실적을 섞는 실패를 근거 검토에서 발견했습니다. 질문한 사업 범위로 생성 지시를 좁히고 주장 수·길이를 응답 스키마에서도 제한했습니다.

고정 개발 사례 7/8 → 개선 후 8/8

비용은 호출 전에 통제

단순 조회에는 LLM을 사용하지 않습니다. AI 호출 전 예산을 예약하고 작업별·사용자별 한도를 적용합니다. 공시·모델·프롬프트가 같은 검증된 답변은 캐시로 재사용합니다.

실제 토큰·비용과 예약금을 함께 기록

Graph 채택도 검증 대상

온톨로지는 기업·기간·지표·근거의 의미를 명시하는 데 사용했습니다. Neo4j는 관계 탐색을 실험하는 PoC이며, 현재 짧은 경로가 SQL보다 유리하다고 단정하지 않습니다.

관계 질의의 가치와 운영 비용을 비교

검증한 범위

자동화 테스트 68개는 합성 모델 응답과 실제 PostgreSQL·Neo4j를 사용합니다. 실제 모델 평가는 고정 개발 사례 8개(분석 5개·범위 차단 3개)이며, 일반 정확도나 독립 환각률이 아닙니다. 최종 8개 평가의 예상 API 비용 합계는 $0.032146입니다.
