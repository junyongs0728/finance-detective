# 데이터 관리

- `seed/company-registry.json`: 검색을 시작하기 위한 공개 기업 목록 스냅샷. 미국 목록의 원출처 URL과 KRX 출처는 각 항목의 `directory_source`에 기록되어 있다. 미국 목록은 공개 미러로 최신·전체 목록을 보장하지 않으며, 선택한 종목은 SEC 공식 제출 정보로 재검증한다.
- `processed/`: 실행 중 생성한 기업별 재무 수치·DART 코드 목록·검색 색인. Git에서 제외한다. 같은 위치에 별도 기업 목록을 생성하면 seed보다 우선 사용한다.
- `raw/`: 외부에서 내려받은 원문. Git에서 제외한다.
- `tests/fixtures/`: 공개 SEC 수치의 작은 고정 스냅샷. 네트워크 없는 테스트용이며 실시간 값이 아니다.

API 키, 사용자 연락처, 개인 보고서는 seed/fixture에 포함하지 않는다. 재무 수치는 출처 URL, 공시 번호, 기간, 통화와 범위를 함께 보관한다.
