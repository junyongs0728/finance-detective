# 실행 예시

실시간 질문은 [README](../README.md)의 로컬 서버와 DB를 실행한 뒤 `http://127.0.0.1:8000/`에서 확인한다. AI 경로는 API 비용이 발생하며 최초 공시 준비 시간이 추가된다.

## 1. 수치 조회

기업 검색에서 쿠팡을 선택하고 `2025년 영업이익 알려줘`를 입력한다.

금액·통화·기간·공시 링크를 확인한다. 이 경로는 구조화된 공시 API와 Python 계산을 사용하며 LLM을 호출하지 않는다. 공급자 정보가 아직 없으면 수집 시간이 필요하다.

## 2. 도구 선택과 계산·출처 추적

`2025년 영업현금흐름에서 영업이익을 뺀 차이를 계산하고 두 수치의 원본 근거 경로를 보여줘`

계산 카드, 분석 과정, 기업과 근거의 관계 탐색을 연다. 2026-09-21 개발 기록에서는 쿠팡 2025 공시 기준으로 `1,773,000,000 - 473,000,000 = 1,300,000,000 USD`를 확인했다. 도구 순서는 `get_financials → calculate_metrics → trace_evidence`였다.

모델은 도구를 선택하지만 계산 입력은 조회된 관측값 ID로 제한한다. 같은 기간·통화인지 검증하고 Neo4j 근거 경로를 SQL 스냅샷과 대조한다. 캐시 응답이면 저장된 실행 기록과 새 호출 비용을 구분한다.

## 3. 공시 기반 설명

애플을 선택하고 `애플이 공시한 공급망 리스크를 설명해줘`를 입력한다. 주장별 인용문, 원문 구간, 공시 링크를 확인한다.

기본 자동 모드에서는 Agent가 검색 도구를 선택한다. ‘공시 검색 답변’ 모드를 선택하면 동일한 생성·검증 모듈을 고정 RAG 경로로 실행한다. 검색 범위는 선택한 공시이며 표·첨부·OCR를 포함하지 않는다.

## 4. 답변 유보

쿠팡을 선택하고 `쿠팡의 2025년 달 기지 운영 사업을 공시 근거로 설명해줘`를 입력한다.

저장된 개발 기록에서는 근거 부족으로 답변을 보류했다. 새 실행의 상태와 근거를 직접 확인한다. ‘검색된 근거로 답할 수 없음’은 ‘공시 전체에 정보가 없음’을 증명하지 않는다.

## 저장된 결과만 확인하기

`http://127.0.0.1:8000/portfolio/`는 [showcase](../showcase) 폴더의 정적 실행 예시를 제공한다. 위 계산, 애플 공급망 설명, 쿠팡 답변 유보의 저장된 결과를 API 호출 없이 볼 수 있다. 기업·질문 선택은 준비된 예시에 한정되며 임의 질문을 실행하지 않는다.

각 사례의 실행 상태·예상 비용·검사 범위는 [평가 문서](evaluation.md)와 [원본 Agent 기록](../evals/agent-report.json)에서 확인한다.
