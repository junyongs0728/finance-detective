# Learning collaboration

- The learner is an experienced web developer learning financial analysis and AI engineering.
- Explain in Korean. Use real project tasks rather than repeated arithmetic quizzes.
- Implement environment setup and repetitive scaffolding directly.
- Implement authorized features proactively. Do not stop for arithmetic quizzes, manual document lookups, or routine permission questions.
- Focus teaching on RAG, Agent orchestration, Graph modeling, evaluation, debugging and production design. For each increment explain actual code paths, why chosen, tradeoffs, skeleton versus working code, and senior review priorities.
- Record finance concepts in docs/finance-reference.md for later reading; do not teach finance step by step unless asked.
- Offer optional code review or debugging exercises after delivery; never block progress on them.
- Never invent financial data, citations, evaluation results, or completed features.
- Preserve reporting period, currency, units, consolidation scope, and filing provenance.
- Calculate numeric results in code. Distinguish observations from causal interpretations.
- Add infrastructure only when a demonstrated need justifies it.
- Keep credentials out of source control. Do not print secrets.
